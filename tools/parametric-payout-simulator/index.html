Parametric Payout Simulator

How does the payout curve change as you move the trigger, exhaust, and limit?

This tool is in build. Want early access or a run tuned to your product structure? Request a demo →

Build spec

Tier
1 — client-side, no backend.
Inputs
Sliders for trigger, exhaust, limit; dropdown for payout shape (linear / stepped).
Compute
payout(index) = clamp((index − trigger) / (exhaust − trigger), 0, 1) × limit.
Output
Live SVG/Canvas payout curve plus a readout table at sample index levels.
Done when
Moving any slider updates the curve in real time, with no network calls.
